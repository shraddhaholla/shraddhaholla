DEPLOYMENT TO GITHUB PAGES
1. Open your GitHub repository.
2. Upload the contents of this ZIP to the repository root (not the ZIP folder itself).
3. Choose to replace the matching website files when GitHub asks.
4. Keep the repository's existing GitHub Pages source set to main / (root).
5. Wait for the Pages deployment to complete, then refresh the website.

No research PDFs or working spreadsheets are included in the public website package.
